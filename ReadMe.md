## About

I started as a frontend engineer and grew into a full-stack role, picking up backend, DevOps, and deployment along the way. Today I build **AI agents in production** for an auto-transport brokerage platform — pairing product-grade UI work with LLM-powered automation.

- 🔭 Currently building **AI agents & LLM automation** for a logistics/brokerage SaaS at **CarLink**
- 🌱 6+ years across Web, Mobile, and Desktop — React, React Native, Electron, Tauri
- 📦 Maintain **[@tolipovjs/rich-text](https://www.npmjs.com/package/@tolipovjs/rich-text)** — a Notion-style rich text editor for React, published on npm
- 📍 Based in Samarkand, Uzbekistan
- 🏆 Finalist, Unicorns Startup Competition (Top 30 of 763, Tashkent 2023 & 2024)
